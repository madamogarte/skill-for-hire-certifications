## 📂 Course Details

### 📊 Data Analytics
- **Duration**: 20 weeks
- **Format**: Online asynchronous with live sessions
- **Completion**: November 2024

**Skills & Topics Covered**:

| Category | Topics |
|----------|--------|
| **Data Analytics & SQL** | Excel proficiency, SQL queries (basic & advanced), relational database design |
| **Python** | Python fundamentals, data wrangling, data visualization, exploratory data analysis (EDA), data science workflows, natural language processing (NLP) |

### 🔐 Cybersecurity
- **Duration**: 16 weeks
- **Format**: Online asynchronous with live sessions
- **Completion**: November 2025

**Week-by-Week Curriculum**:

| Weeks | Topic |
|-------|-------|
| 1-2 | Network Concepts, Protocols & Security Basics |
| 3-5 | Python Fundamentals, Functions & Libraries |
| 6-7 | Cryptography: The Big Picture & Practical Encryption with Python |
| 8-10 | Log File Analysis, Network Activity & Packet Analysis, Malware Detection with Python |
| 12-16 | Certified in Cybersecurity (CC) Domains: Security Principles, Business Continuity & Disaster Recovery, Access Controls, Network Security, Security Operations |
| 17-20 | Cloud Fundamentals, Core Services, Security & Architecture |

**Key Skills Acquired**:
- Network configuration, monitoring, and security
- Python programming for security automation and analysis
- Cryptography (hashing, symmetric/asymmetric encryption)
- Log file analysis automation
- Packet analysis with Scapy
- Malware detection and analysis workflows
- Certified in Cybersecurity (CC) domains
- Cloud computing concepts and security

📄 **Detailed Curriculum**: [Pluralsight Content List - Cybersecurity](https://skillsforhire.ca/app/uploads/2023/08/PluralSight-Content-List.pdf)

### 🤖 Data Analytics & AI (Growth Edition)
- **Duration**: 8 weeks
- **Level**: Intermediate
- **Format**: Online blended learning with live sessions
- **Completion**: March 2026

**Skills & Topics Covered**:

| Category | Topics |
|----------|--------|
| **Advanced Data Engineering** | Advanced SQL querying and manipulation, data transformation with Python and Pandas |
| **Business Intelligence** | Interactive dashboards and visualizations |
| **Machine Learning** | Regression, classification, clustering, model evaluation |
| **Advanced AI** | Neural networks, generative AI workflows |
| **Applied Project** | End-to-end analytics/AI project addressing real-world problems |

**Key Achievements**:
- Query and manipulate large datasets using advanced SQL techniques
- Analyze and transform datasets using Python and Pandas workflows
- Develop interactive dashboards and visualizations to communicate insights
- Apply machine learning models including regression, classification, and clustering
- Evaluate model performance and select appropriate analytical approaches
- Understand the role of neural networks and generative AI in modern data workflows
- Design and implement an end-to-end analytics or AI project addressing a real-world problem
- Communicate technical findings and analytical decisions clearly to stakeholders
